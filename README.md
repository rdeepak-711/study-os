# study-os

A public log of leveling up backend engineering and system design while working full-time. 16 weeks, most evenings, building from scratch and writing it down as I go.

## What I'm working through

- **Distributed data** — Designing Data-Intensive Applications (DDIA): data models, storage & indexing, replication, partitioning, transactions & isolation.
- **System design** — designing canonical systems out loud: URL shortener, rate limiter, notification service, job queue, news feed, chat.
- **SQL depth** — indexing, `EXPLAIN`, window functions, CTEs, fixing N+1, query optimization with before/after benchmarks.
- **Scale** — load testing (k6), caching patterns, measuring p95 under load.
- **Backend fundamentals** — API design, auth & authz, observability, security basics.
- **DSA** — Striver's SDE sheet, solved from scratch (no AI), kept here as I go.

## How I work

Deliberate practice: I build and solve things **from a blank file, without AI assistance**, then review. The point is to own the fundamentals, not just ship with a copilot.
